# AnomalousWeather

Плагин аномальной погоды для **Paper 1.21+** (собран и протестирован на Paper 1.21.11-132).

Аномалии запускаются **поверх обычной погоды** — ванильный дождь/гроза и смена дня
не отключаются. Каждая аномалия заметно выделяется:

* **BossBar** с названием аномалии, цветом и таймером обратного отсчёта;
* **тайтл** на весь экран при старте;
* **частицы** вокруг игроков (у каждой аномалии свой цвет/тип);
* **фоновые звуки** (у каждой аномалии свой);
* **подсказка в actionbar**, какой предмет защиты нужен;
* **«личный» дождь** для игрока (`visual-fake-weather`) — аномалию видно даже
  в ясную погоду, при этом погода сервера не меняется.

## Аномалии и защита

| Аномалия | Что делает | Предмет защиты | Слот |
|---|---|---|---|
| ☣ Кислотный дождь | урон, яд, ломает броню; в воде не действует | Кислотостойкий шлем | голова |
| ☄ Огненный дождь | урон и поджог всего под открытым небом | Огнеупорная мантия | нагрудник |
| ❄ Снежная буря | урон, заморозка, замедление | Утеплённые сапоги | сапоги |
| ≋ Песчаная буря | урон, слепота, голод, замедление | Пылезащитные штаны | штаны |
| ☠ Токсичный туман | урон, яд, тошнота — действует даже под крышей | Свинцовая маска | голова |
| ⚡ Грозовая аномалия | частые молнии в игроков без защиты | Громоотводный оберег | левая рука |
| ✵ Эндер-шторм | рандомная телепортация, тошнота | Эндер-оберег | левая рука |

Рецепты защиты **открыты в книге рецептов с самого начала игры**
(`protection.recipes.unlock-on-join: true`). Отключить рецепты целиком можно
через `protection.recipes.enabled: false`.

Предметы защиты помечены скрытым ключом (PDC), поэтому переименованная
вещь защитой **не** считается. Если предмет надет/взят в нужный слот —
урон не проходит, негативные эффекты блокируются, броня не портится.
Эндер-оберег дополнительно нельзя выбросить (Q), повесить в рамку или
вставить в рамку портала Края — он не потеряется
(`protection.items.VOID_STORM.prevent-drop: true`; при желании можно
включить это и для других предметов). Для эндер-оберега эта защита
включена по умолчанию даже в старых конфигах, где ключа ещё нет.

## Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/anomaly status` | текущая аномалия и таймер | `anomalousweather.status` |
| `/anomaly list` | все аномалии, их шансы и защита | `anomalousweather.status` |
| `/anomaly protection` | список предметов защиты | `anomalousweather.status` |
| `/anomaly start <тип> [сек]` | запустить аномалию вручную | `anomalousweather.admin` |
| `/anomaly stop` | остановить аномалию | `anomalousweather.admin` |
| `/anomaly give <игрок> <тип>` | выдать предмет защиты | `anomalousweather.admin` |
| `/anomaly reload` | перечитать конфиг | `anomalousweather.admin` |

Алиасы: `/aw`, `/аномалия`.

## Настройка шансов

В `config.yml` за шансы отвечают два параметра:

```yaml
settings:
  check-interval-seconds: 90     # раз в 90 секунд бросается «кубик»
  anomaly-chance-percent: 35     # 35% что аномалия вообще начнётся

weathers:
  ACID_RAIN:
    chance: 25                   # вес аномалии
```

Итоговый шанс аномалии = её `chance` / сумма `chance` всех включённых аномалий.
Проценты по каждой аномалии можно посмотреть командой `/anomaly list`.
Чтобы аномалия никогда не выпадала — поставьте `enabled: false` или `chance: 0`.

## Основные настройки

```yaml
settings:
  worlds: [ "*" ]                     # миры, где работает плагин
  require-vanilla-rain: false         # аномалии только во время ванильного дождя
  override-vanilla-weather: false     # НЕ менять серверную погоду (по умолчанию)
  visual-fake-weather: true           # «личный» дождь игроку для визуала
  ignore-creative: true               # не задевать креатив
  immunity-permission: ""             # нода-иммунитет, напр. anomalousweather.immune
  effect-radius: 12                   # радиус частиц/урона по мобам
```

Если `override-vanilla-weather: true`, на время аномалии включается серверный
дождь (для грозовой аномалии — ещё и гроза), а после окончания возвращается
ровно то состояние, что было до неё.

## Сборка

Нужен **JDK 21** и **Maven**:

```bash
mvn -DskipTests package
```

Готовый jar появится в `target/anomalous-weather-1.0.0.jar` — положите его
в папку `plugins` сервера.

## Структура конфига

* `settings` — общие настройки (миры, шансы, тайминги, объявления);
* `weathers.<ТИП>` — настройки каждой аномалии (шанс, длительность, урон,
  эффекты, частицы, звук, особые параметры вроде `lightning` и `teleport`);
* `protection.items.<ТИП>` — предмет защиты: материал, слот, название, лор,
  `damage-reduction` (1.0 — полная защита) и `blocks-effects`;
* `messages` — все тексты в формате MiniMessage.
